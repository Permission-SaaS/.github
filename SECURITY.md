# Política de segurança

## Versões com suporte

Só o branch `main` de cada repositório recebe correções de segurança. As tags de entrega das
disciplinas (`etapa-*`, `arq-etapa-*`) são registros congelados de avaliação e não são atualizadas.

| Versão                         | Suporte            |
| ------------------------------ | ------------------ |
| `main`                         | :white_check_mark: |
| tags `etapa-*` e `arq-etapa-*` | :x:                |

## Como reportar uma vulnerabilidade

**Não abra uma issue pública.** Use o reporte privado do GitHub: na aba **Security** do
repositório afetado, clique em **Report a vulnerability**. Só o mantenedor vê o relato.

Se puder, inclua o repositório e o endpoint ou arquivo afetado, os passos para reproduzir e o
impacto esperado.

O projeto é mantido por uma pessoa, então não há prazo garantido de resposta. Todo relato é lido e
respondido, dizendo se foi aceito ou recusado e por quê. Se for aceito, a correção vai para o `main`,
e o relato pode ser publicado depois que ela estiver no ar.
